Research & Technical Projects

Road Maintenance Scheduling using Reinforcement Learning

Developed a web-based decision support system for predicting road maintenance needs using satellite imagery. The platform segments road networks and predicts repair priorities using reinforcement learning models combined with geospatial graph analysis.

The project introduced a circular patch based sliding window algorithm and an intersection point analysis framework implemented with QGIS tools to better understand road connectivity and infrastructure health.

Graph Convolution Based Activity Closeness Estimation

Proposed a novel method for analyzing similarity between human activities using graph neural networks and pose estimation models. The research combines video analysis, dynamic graph structures and graph convolutional networks to better understand motion similarity patterns.
